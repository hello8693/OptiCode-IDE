# 题目列表超级面板（主面板）设计稿

> 目标：让用户在“题目列表”中完成题目浏览、组织与常用操作，减少对目录结构的依赖；提供清晰的树状结构，且具备“题解/样例/源码”等题目资产的管理入口。

## 1. 设计原则
- **题目为中心**：所有操作围绕题目实体展开，目录结构退居二线。
- **树状结构清晰**：题目 -> 资产（源码 / 样例 / 题解 / 其他文件）。
- **高密度但可扫读**：行高适中、信息密度高、状态一眼可见。
- **操作就地完成**：常用操作不跳转、少弹窗。
- **符合 IDE 组件风格**：使用现有主题变量和组件样式，不突兀。

## 2. 信息架构
### 2.1 顶部工具区（Header）
- 标题：题目列表
- 搜索框：按题号/关键词过滤
- 分组切换（Tab 或 Segmented）
  - 全部 / 最近 / 收藏 / 未完成 / 已通过（可选）
- 右侧操作：
  - 新建题目
  - 重新扫描
  - 设置（入口：题目结构约定）

### 2.2 主树视图（Tree）
树状结构示例：
```
P1001  (OJ: Luogu)  [C++]  [最近]  [★]
  ├─ 源码
  │   └─ P1001.cpp
  ├─ 样例
  │   ├─ sample-1.in
  │   ├─ sample-1.out
  │   └─ samples.json
  ├─ 题解
  │   ├─ README.md
  │   └─ 草稿.md
  └─ 其他
      └─ notes.txt
```

节点类型：
- **题目节点（一级）**：显示题号、题名、OJ 标签、语言、收藏状态、状态徽标（未编译/编译失败/通过/未通过）
- **资产分类节点（二级）**：源码、样例、题解、其他
- **文件节点（三级）**：实际文件

### 2.3 右键菜单
- 题目节点：
  - 打开源码
  - 新建题解（README.md 或 note.md）
  - 添加样例
  - 打开题目文件夹
  - 删除题目
- 文件节点：
  - 打开
  - 重命名
  - 删除

### 2.4 底部状态区（Footer）
- 扫描耗时 / 题目数量 / 最近更新

## 3. 交互设计
### 3.1 题目节点
- 单击：展开/折叠
- 双击：打开源码
- Hover：显示快速操作按钮（打开源码、创建题解、更多）

### 3.2 文件节点
- 单击：打开

### 3.3 快捷创建
- 题目节点右侧 “+” 快速创建题解/样例
- 空状态下显示“创建题目”按钮

## 4. 数据与结构
### 4.1 依赖服务
- `IProblemService.listProblems()` 作为题目入口
- `IWorkspaceService` 获取根目录
- 新增：
  - `ProblemAssetService`（可选）用于扫描题解/样例结构

### 4.2 题目目录约定
```
{problemId}/
  {problemId}.cpp
  samples/
    samples.json
    sample-1.in
    sample-1.out
  solution/
    README.md
```

## 5. UI 组件与样式
- 使用 `oi-panel` 基础样式
- 新增 `problem-tree` 样式
  - 行高 28px
  - 图标 14px
  - 折叠箭头
- 状态徽标：
  - `pass` 绿色
  - `fail` 红色
  - `pending` 灰色

## 7. 分阶段实现计划
1) **阶段一：树形 UI + 基础操作**
- 用现有 `ProblemListPanel` 替换为 tree 结构
- 展开/折叠 + 打开源码/样例/题解
- 新建题解/样例按钮

2) **阶段二：状态与过滤**
- 收藏 / 最近 / 状态徽标
- 搜索 + tab 过滤

3) **阶段三：增强能力**
- 批量操作
- 题目标签
- 题解模板

## 8. 需要新增的命令

## 10. 验收标准
- 题目列表可视为主要入口
- 题目结构清晰
- 题解与样例可在树内快速创建
- **UI 与现有 IDE 视觉一致**
